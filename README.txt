PharmaCare - Pharmacy App
=========================
Files: index.html, manifest.json, sw.js, icon-192.png, icon-512.png
(All files must stay together in the same folder.)

1) Quick use on computer (no install)
   Double-click index.html. It opens in your browser.

2) Install as an app on mobile + desktop (needs HTTPS)
   - Upload ALL files to GitHub Pages (same as SchoolApp).
   - Android (Chrome): open the link > menu (3 dots) > "Install app".
   - iPhone (Safari): open the link > Share > "Add to Home Screen".
   - Windows/Mac (Chrome or Edge): open the link > click the Install icon in the address bar.
   After the first visit the app also works offline.

Note: data is saved inside each browser/device separately. Use Reports > Backup to move data between devices.
